# 🏃 Baton Build Kit — دليل الاستعمال (اقرأ هذا أولًا)

هذه الحزمة هي كل ما يحتاجه Claude Code لبناء مشروع **Baton** كاملًا:
أداة CLI مفتوحة المصدر توحّد اشتراكاتك (Claude Max + ChatGPT + Gemini) عبر تشغيل
الأدوات الرسمية نفسها، مع تتابع تلقائي (relay) عند انتهاء حدود الاستخدام — بدون لمس
أي توكن، وتعمل على **macOS و Windows** معًا.

## محتوى الحزمة

| الملف / المجلد | دوره |
|---|---|
| `00-MASTER-PROMPT.md` | **البرومبت الكامل** الذي تلصقه في Claude Code |
| `CLAUDE.md` | ذاكرة المشروع — يقرأها Claude Code تلقائيًا في كل جلسة |
| `docs/` (9 ملفات) | المواصفات المرجعية: المعمارية، الـ adapters بالأعلام المُتحقق منها، الـ relay وقالب HANDOFF، التوجيه، تتبع الاستهلاك، قواعد Windows/macOS، الهوية البصرية، المراحل M0→M8، الاختبارات |
| `.claude/skills/` (6 مهارات) | مهارات تنشّط تلقائيًا أثناء البناء: تطوير adapter، أمان cross-platform، بروتوكول HANDOFF، كشف الحدود، هوية الواجهة، قائمة النشر |
| `.claude/settings.json` | صلاحيات جاهزة لجلسة البناء (تمنع `npm publish` وقراءة مجلدات المزودين) |

## خطوات التشغيل (5 دقائق)

```bash
# 1) أنشئ مستودعًا فارغًا
mkdir baton && cd baton && git init

# 2) انسخ محتوى الحزمة إلى جذره (بما فيها المجلدات المخفية!)
#    يجب أن ترى: CLAUDE.md ، docs/ ، .claude/ ، 00-MASTER-PROMPT.md

# 3) commit أولي
git add -A && git commit -m "chore: baton build kit"

# 4) شغّل Claude Code داخل المجلد (بأقوى موديل متاح عندك)
claude

# 5) الصق محتوى 00-MASTER-PROMPT.md كاملًا كأول رسالة، واتركه يعمل
```

سيبني Claude Code المشروع مرحلة بمرحلة (M0 → M8) حسب `docs/MILESTONES.md` مع
اختبارات و CI على الأنظمة الثلاثة. راقب نهاية كل مرحلة وتأكد أن CI أخضر قبل السماح
له بالمواصلة إن توقف.

## قرارات محسومة داخل الحزمة (غيّرها قبل البدء إن أردت)

- **الاسم:** Baton — حزمة npm باسم **`baton-ai`** (تحققتُ أن الاسم متاح، بينما
  `baton` و`baton-cli` محجوزان) والأمر في الطرفية **`baton`**.
- **مزودو النسخة الأولى:** Claude Code + Codex + Gemini فقط. إضافة Kimi لاحقًا =
  مجلد adapter واحد بفضل المعمارية.
- **الرخصة:** MIT. **الألوان:** بنفسجي/سماوي (ممنوع البرتقالي حتى لا يشبه Claude Code).
- **النشر إلى npm يدوي** — البرومبت يمنع Claude من النشر؛ أنت من يكتب
  `npm publish` بنفسك بعد المراجعة.

## بعد اكتمال البناء

1. جرّب السيناريو الكامل على جهازيك (Mac ثم Windows): `baton doctor` →
   `baton run "..."` → حد مُصطنع عبر `BATON_TEST_FORCE_LIMIT` → شاهد الـ relay.
2. أنشئ الريبو على GitHub (باسمك الشخصي أو Thinkxie — قرارك التسويقي) وارفع.
3. `npm publish` ثم فيديو الإطلاق: لقطة إعلان الـ relay (⚡ → 🏃) هي اللقطة
   التي ستنتشر.

**ملاحظة صيانة:** الأعلام في `docs/ADAPTERS.md` مُتحقق منها بتاريخ أوت 2026، لكن هذه
الأدوات تتغير بسرعة — البرومبت يأمر Claude بمطابقتها مع `--help` الحقيقي عند البناء
وتحديث الوثيقة، فلا تقلق إن تغير شيء.
