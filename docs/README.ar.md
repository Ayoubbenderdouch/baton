## ما هو Baton؟

أنت تدفع اشتراك Claude Max واشتراك ChatGPT ولديك حساب Google. لكل واحد أداة سطر أوامر
رسمية، ولكل واحد حدّ استعمال خاص به يوقفك في منتصف العمل.

يشغّل Baton هذه الأدوات الرسمية نفسها، يختار الأنسب منها للمهمة، وعندما ينتهي حدّ أحدها
يكتب ملف تسليم `HANDOFF.md` ويمرّر **المهمة نفسها** إلى الأداة التالية — بلا إعادة شرح
وبلا بداية من الصفر.

## البداية في ثلاث خطوات

```bash
npm i -g baton-ai
baton doctor
baton run "أصلح اختبار المصادقة المتقطع"
```

- `baton doctor` يخبرك أي أداة مثبّتة وأيها تحتاج تسجيل دخول، ويطبع أمر الإصلاح الرسمي
  الخاص بالمزوّد نفسه.
- `baton run "المهمة"` يوجّه المهمة، يعرض العمل مباشرة، ويمرّر العصا تلقائيًا عند الحد.
- `baton continue` يكمل المهمة في اليوم التالي.
- `baton status` يعرض الاستهلاك وفترات التبريد لكل الأدوات في جدول واحد.

## الأمان: لا نلمس بيانات دخولك أبدًا

- لا يقرأ Baton ولا يخزّن ولا يرسل أي توكن أو مفتاح API، ولا يعدّل
  `~/.claude` أو `~/.codex` أو `~/.gemini`.
- لا يقوم Baton بأي اتصال بالشبكة من تلقاء نفسه: لا تتبّع، ولا تحديثات صامتة.
  الجهات الوحيدة التي تتصل بالمزوّدين هي أدواتهم الرسمية.
- لا توجد سكربتات `postinstall`.
- حسابك يبقى بالكامل داخل أداة كل مزوّد وبشروطه.

## كيف يعمل التمرير (relay)؟

1. تذهب المهمة إلى الأداة المناسبة.
2. تُسجَّل كل جولة في `.baton/session.json`، ويُحدَّث `HANDOFF.md` في جذر المشروع.
3. عند بلوغ حدّ الاستعمال: تُسجَّل فترة تبريد، ويُكتب ملف التسليم، وتبدأ الأداة التالية
   بقراءته والمتابعة من حيث توقّفت الأولى.
4. حماية من الدوران: لا عودة إلى أداة استنفدت حدّها في المهمة نفسها، ولا تمرير عند خطأ
   ليس حدَّ استعمال (إلا إذا طلبت `--relay-on-error`).

## التوجيه الافتراضي

| نوع المهمة | الأداة | السبب |
|---|---|---|
| تصحيح الأخطاء والمعمارية | `claude` | أصعب تفكير على أندر الساعات |
| كتابة الميزات والاختبارات | `codex` | حجم العمل اليومي |
| التلخيص والمراجعة والنصوص الطويلة | `gemini` | سياق طويل وأسئلة رخيصة |

يمكنك إضافة كلمات مفتاحية بالعربية:

```bash
baton config set rules '[{"match":{"keywordsAny":["لخص","اشرح","راجع"]},"agent":"gemini"}]'
```

## تجربة التمرير دون استهلاك حصتك

```bash
BATON_TEST_FORCE_LIMIT=claude baton run "اكتب كلمة ok"
```

يتظاهر Baton بأن claude بلغ حدّه (دون تشغيله أصلًا)، فترى التمرير كاملًا: كتابة ملف
التسليم، ثم إكمال الأداة التالية للمهمة.
